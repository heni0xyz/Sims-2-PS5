# 0.1.0-alpha.1

First owner-copy builder preview. The Windows exe bundles tools and public
runtime/RADV; it privately generates/compiles code and extracts data from your
USA Xbox ISO. Public PS5 ZIP: native4K Open Sans preparation screen, no game code.
All authored source is consolidated into Sims-2-PS5.

Host evidence: 65 fresh O2 units in 557.84s, initial link-export error corrected,
verified-object retry through link/sign/inspect/private install in52.64s.
Public instruction title: 29 objects, native packaging and symbol audit PASS.
The native linker used about696MiB peak working set. Whole-system RAM minimum
is not measured. See recomp/docs/BUILDER_RELEASE.md for limits and hashes.

Known issues: variable gameplay performance, occasional thin Continue background,
unverified full-game/stability coverage. This new Windows-linked result/public
screen still needs real PS5 execution validation. Windows8.1/Catalina tests and
Mac app/native kit are not complete. No stable60 claim. No Mac app attached.
