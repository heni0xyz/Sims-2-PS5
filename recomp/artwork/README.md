# Title artwork

Provided by **szampan**, 31 October 2026, for The Sims 2 PS5 homebrew title
and its planned GitHub repository. Original PNGs and editable Pixlr PXZ
projects are retained unchanged under source/; provenance.json records hashes.
szampan dedicates these four artwork source files and their generated shell
images under **CC0-1.0**, selected explicitly on 31 October 2026. The full
legal text is in CC0-1.0.txt; original author attribution remains in credits.

`python tools/ps5/prepare_branding.py` produces a 512x512 icon0.png and
1920x1080 RGBA pic0.dds/pic1.dds using the provided composition. Originals
are never overwritten. PXZ files do not enter the PS5 title. The existing
template title recipe handles installation of the generated shell artwork.
