Installer carousel images go here as `preview-1.png`, `preview-2.png` and
`preview-3.png`, in 16:9. The build stages only explicitly supplied images from
this folder. Until these are supplied, the launcher uses its CC0 background.

section; the right stick browses the three images. Artwork changes update the
public resource fingerprint without invalidating compiled guest code.
