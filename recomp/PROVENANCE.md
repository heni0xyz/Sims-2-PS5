## Independent completion-callback fix

The runtime pin 53ef20713bba1a22226708f962fe59fcfbf6098d adds an optional
D3DDevice_InsertCallback implementation in the MIT SDK. Its address, argument
order, NV2A packet and frame-semaphore callback were derived from this project's
verified XBE/generated annotations and read-only runtime probes. The original
game project's hooks/config were not an input. Private logs retain the failing
wait and the subsequent 540-frame bounded host run. The implementation uses
the existing backend completion barrier and guest dispatcher, not a skipped
initialization or fake completion signal. It has not yet been tested on PS5.

The following local pin 0032d32b870e9daeb278a0fdf9badf03d95d8339 propagates
Vulkan submission/completion errors instead of continuing to a guest callback,
and bounds fence waits at five seconds. Pending resources are retained on
failure. Real GPU failure-path execution remains to be validated on a Vulkan
host/console; CPU null-backend tests do not cover it.

The recompiler SDK local pin faeb0eaca270e01a9e83bb2bc587c824c458ac32 changes
only harness portability and diagnostics; the original TGP482 tool code remains
at the public base. Additional wrappers and tests retain their stated authors.
