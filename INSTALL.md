# Installation

Use your own **The Sims 2 (USA), Original Xbox** ISO. Other revisions are refused.

Extract the entire **Windows Portable ZIP** once. Keep `kit/` and `_internal/`
beside **The Sims 2 Builder.exe**, run that small executable, select the ISO,
choose a new output folder and click Build. Allow around 10–20 minutes on an older mobile i7/SSD; this is an
estimate based on the development PC, not a timing guarantee. At least 4 GiB
free in the output location is checked; the ISO itself and builder take more
space. Minimum RAM and older OS compatibility have not been certified.

Copy the finished **PPSA99145** folder to PS5 using your normal prepared
homebrew folder launcher. Keep `eboot.bin`, `sce_sys`, `sce_module`, shaders,
public resources and extracted `assets` together. The title must be closed
while copying. The builder never deletes your ISO.

If updating, preserve the existing `hdd` folder and saves; build into a new PC
folder and transfer the resulting files deliberately. Do not erase saves to fix
a build error. A failed build preserves diagnostics beside the output directory.
Retry in the same GUI can reuse checked objects when its cache matches.

The setup ZIP is optional; use **The-Sims-2-PS5-Setup-WindowsLink.zip** and keep
its `assets/README.txt`. It only shows the preparation instructions until you
replace it with the complete private title generated by the builder. Do not
upload your completed game folder, generated eboot, ISO or extracted game data.
